Reference

    
The whole language fits on a card.

    

      

        
Syntax

        
find <types> [where <cond> and <cond> …]

        

          
=  !=equals / differs (== works too)

          
~=  !~regex search / no match

          
< <= > >=numeric comparison

          
not attrattribute is empty or false

          
a, bseveral types (or a or b)

          
x.y.zfollow nested attributes

        

        
Values can be 'quoted', "quoted", numbers or bare words. Attributes that hold AST nodes compare by their source, so func = 'os.path.join' just works. Lists match if any element matches.

      

      

        
Node types

        

          
functionFunctionDef, AsyncFunctionDef

          
classClassDef

          
callCall

          
importImport, ImportFrom

          
loopFor, AsyncFor, While

          
for_loop · while_loopFor / While

          
assign · return · raise…and many more aliases

          
anyevery node

        

        
Any class from Python's ast module works too, as FunctionDef or function_def, including abstract ones like stmt and expr.

      

      

        
Virtual attributes

        

          
lineslines the node spans

          
argcparameters / call arguments

          
docstringmodule, class or function docstring

          
namedotted name of a call: os.path.join

          
sourcethe node's code

          
line · col · typeposition and class name

        

        
Not sure what a node is called? Open the ast tab (or run astq --dump file.py) to see every node and attribute.

      

    


    

      
# install from GitHub (no dependencies)
$ pip install git+https://github.com/chandana-galgali/AST-Query
# search a whole project
$ astq "find function where lines > 40 and not docstring" src/
# script-friendly output
$ astq --json "find call where func = 'eval'" .
$ astq -c "find class where bases ~= 'Exception'" .

      
$ astq "find call where func = 'print'" .
